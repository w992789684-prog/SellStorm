# SellStorm

AI 带货助手：输入商品，一键出爆款口播、卖点文案、短视频脚本。

## 用法

打开 `index.html` 即可使用（手机、电脑都适配），也可以用 GitHub Pages 部署：

仓库 Settings → Pages → Branch 选 main → 保存，打开给出的链接就能用。

## 功能

- 填产品名、价格、卖点、痛点，选平台（抖音直播/短视频、小红书、淘宝、快手、视频号）和语气
- 一键生成 38 条内容：6 段直播话术、5 条 30 秒短视频口播脚本、5 篇图文文案、10 张 AI 主图提示词、12 条标题
- 每条可单独复制，也可整类复制或下载 txt
- 利润计算器：填成本、扣点、佣金、退货率，算每单净赚、利润率和投流保本线
- 内置示例：保温杯、空气炸锅、口红、防晒衣、台灯，一键切换
